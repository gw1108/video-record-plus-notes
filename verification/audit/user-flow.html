User flow — from a recorded playtest to an unlisted YouTube video

Steps 1–4 are entirely local. Google is involved only at step 5 (consent, first run) and step 7 (the single API call) — and step 7 happens only after the user has reviewed exactly what will be sent. One video per upload, always started by a button press.

local only
1

Record a session

OBS records the developer's own game session. A hotkey marks interesting moments; the developer dictates a note at each mark.

local only
2

Process it on the machine

FFmpeg cuts the recording down to the marked moments; local speech-to-text turns each dictated note into text. Nothing leaves the PC.

local only
3

A title and description are drafted

Generated from the user's own notes: one chapter timestamp per note, in the condensed video's timeline. Written to local text files.

local only
4

The user presses Publish

In the app's Sessions list. This opens the Publish dialog — still no network call.

google consent
5

Sign in with Google

First run only (and after the token expires). The system browser opens Google's consent screen for the single scope youtube.upload. The token is cached locally.

local only
6

Review, then confirm

The dialog shows the title, the full description with its chapters, and a visibility select that defaults to Unlisted. All of it is editable. Nothing is sent until Upload is pressed.

api call
7

videos.insert

The one API call: a resumable upload of that single file, with the reviewed metadata. A progress bar tracks it and the user can cancel. 1,600 quota units.

local only
8

The link comes back

The dialog shows the youtu.be link with Watch, Edit in Studio and Copy link. The URL is saved to a local file. Nothing is read back from YouTube.

Every upload is deliberate

No background, scheduled, batched or bulk uploads exist in the product. One press of Upload uploads exactly one video, and a second press on the same session warns that it would create a second video.

What the user controls at every step

  • The content. Their own recording, on their own channel; title and description editable before upload.
  • The visibility. Unlisted by default; private and public are the other choices.
  • The access. Sign-out deletes the local token, and access is revocable at myaccount.google.com/permissions.
