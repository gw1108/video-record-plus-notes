OBS connection

Auto-detect reads OBS's own WebSocket settings (port + password) and, if the server is off and OBS is closed, turns it on for you. Otherwise flip it on in OBS → Tools → WebSocket Server Settings.

Preflight verifies Hybrid MP4 (chapters + crash recovery), mic on audio track 2, and a hardware encoder. Encoder tuning (single-pass CQP, psycho-visual tuning off, lookahead off) must be set in OBS itself — see the checklist in the README.
