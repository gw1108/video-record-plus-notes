    Sessions

    Every session in the sessions folder. Run pipeline spawns playtest-pipeline with the settings below and streams its output into the log; Open report opens the finished report.html; Publish uploads the condensed cut to YouTube (unlisted) with the notes as chapters; Delete asks first, then moves the session folder to the Recycle Bin.

    OBS connection

    Auto-detect reads OBS's own WebSocket settings (port + password) and, if the server is off and OBS is closed, turns it on for you. Otherwise flip it on in OBS → Tools → WebSocket Server Settings.

    Preflight verifies Hybrid MP4 (chapters + crash recovery), mic on audio track 2, and a hardware encoder. For 1080p, set H.264 High Profile with VBR 8 Mbps at 24/25/30 fps or 12 Mbps at 48/50/60 fps. Encoder tuning must be set in OBS itself; see the checklist in the README.

    Hotkeys & options

    Click a key button, then press the input to bind: any keyboard key (with Ctrl/Shift/Alt), any mouse button, a foot pedal (set it to send a key), or an Xbox/HID controller button. Esc cancels. Mouse and controller bindings always use the Raw Input helper; the capture-mode setting applies to keyboard bindings only.

    Post-session pipeline

    Segment policy: each mark keeps [mark − before, mark + after], grown to enclose any dictated sentence, and segments closer than the merge gap join. These flags are baked into the pipeline command shown after every session.

    YouTube upload

    Publishing spawns playtest-youtube (install it with pip install -e "pipeline[youtube]"). Sign-in happens once in your browser and the token is cached in %APPDATA%\playtest-recorder. Until Google's compliance audit passes, uploads stay private whatever you pick here.

    Session

    Starting closes this window — the recorder runs from the tray. Press the mark key when something interesting happens and dictate a note; press stop from the tray when done.
